# Portfolio captures

Replace the README placeholders when the MVP is stable. Avoid personal data in demo tasks.

Suggested files:

- `board-light.png`: complete board in the light theme;
- `board-dark.png`: complete board in the dark theme;
- `drag-and-drop.gif`: movement between columns and reordering;
- `task-editor.png`: creating or editing a task;
- `offline.gif`: editing offline, restarting, and preserving the result.

Use a consistent device, crop unnecessary frames, and compress files before committing. For accessibility, describe in the README what each capture demonstrates.
